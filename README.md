# 线束布线板投影指引设计与校验系统

纯前端、离线运行的 TypeScript + WebGL2 应用。工装板、导线表、投影仪、步骤和校验设置全部保存在浏览器 IndexedDB，不依赖后端服务。

## 启动

```bash
npm install
npm run dev
```

打开终端输出的 `http://127.0.0.1:5173/`。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

命令行投影精度校验：

```bash
npm run verify
```

该脚本会生成 200 根导线、配套工装板和 3 台投影仪，对全部接插件孔框角点及可见的线束跨中堆高点做矩阵反投影、像素量化和射线落点校验。当前种子方案的孔位框最大偏差约 1.19 mm，可见堆高样本最坏约 1.30 mm；完全无视线的交叉点单独计入遮挡样本并进入可见率/加机建议，不与投影映射误差混淆。

## 页面

1. **工装板**
   - 2400×1200 mm 实际尺寸板。
   - 叉子、托架、线托、胶带点、接插件座可点击放置、拖拽、旋转、复制和删除。
   - 支持导入 ASCII DXF（LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC），自动适配板面并持久化。
2. **导线表**
   - 内置确定性生成的仪表板线束：200 根线、16 个 32 孔接插件。
   - 线号、回路、截面、实物颜色、两端接插件/孔位、长度和路径。
   - 支持 CSV 导入/导出和模板下载；按叉子网络 A* 自动布线，计算共享段、分支点、捆扎点和堆高。
3. **投影仪布置**
   - 设备卡记录分辨率、投射比、镜头位移、亮度、原生对比度。
   - 最多 4 台；俯视图实时显示视锥覆盖多边形和最佳像素密度 PPI 网格。
   - 侧视图可直接拖拽机身调吊装高度/前后位置，俯角和参考画面尺寸实时更新。
   - 融合带宽度可调，shader 中使用边缘 smoothstep 权重和权重归一化，避免重叠区叠加白带。
4. **指引编排**
   - 200 个布线步骤，可连续播放。
   - 当前导线按实物颜色生成带白色描边和流动光流的箭头；目标孔位生成闪烁红框。
   - 每段箭头/每条孔框边独立选择可见性和像素密度最佳的投影仪；主投影仪被手臂或线束挡住时自动换台或分段分摊。
   - 每步计算可见率、遮挡原因、最低对比度、PPI 和落点误差；低可见率步骤可导出 CSV，并给出加机/挪机坐标建议。
5. **工位预览**
   - 板前真人比例视角、轴测和俯视。
   - 车间顶灯照度会抬高黑位并降低投影对比度；可开启红色脉冲热力图标记不满足对比度阈值的板面区域。
   - 工人身体、头、手臂和手掌使用与 CPU 射线校验一致的胶囊体，WebGL 深度图和报告使用同一套遮挡近似。

## 关键实现

- `src/lib/types.ts`：领域模型，单位统一为 mm。
- `src/lib/seed.ts`：确定性示例项目。
- `src/lib/routing.ts`：叉子图、A* 路径、共享段负载、线束半径/堆高、分支和捆扎点。
- `src/lib/projectors.ts`：离轴镜头矩阵、视锥覆盖、PPI、对比度、射线-胶囊/盒体遮挡。
- `src/lib/guide.ts`：步骤投影方案、可见率报告、3 mm 精度校验、设备建议。
- `src/webgl/Renderer.ts`：WebGL2 渲染器；每台投影仪先渲染 1536² 编码深度图，主 shader 再做投影贴花、深度判遮挡、边缘融合和对比度热力图。
- `src/webgl/slides.ts`：按投影仪像素坐标绘制箭头、流动虚线、线号和闪烁孔框。
- `src/lib/db.ts`：IndexedDB 对象仓库。

## 3 mm 精度如何保证和验证

系统不把指引简单当成平面 PNG 贴在 `z=0`：

1. 孔位框角点使用接插件孔位的真实三维高度。
2. 线束箭头使用由截面、共享导线数量和排布系数计算出的堆高路径。
3. 每个期望点经投影仪 `VP` 矩阵投影到设备像素，再用自身 NDC 深度反投影，检查矩阵数值误差。
4. 从投影仪光心向期望点发射射线，与线束胶囊、叉子胶囊、托架/接插件盒体、工人手臂求交；若最近遮挡面在期望点之前，计算实际落点到期望点的三维偏差。
5. 加上投影像素量化误差 `0.5 / pxPerMm` 和现场标定残差。
6. 只有最差样本不超过设定公差（默认 3 mm）时，精度卡才显示通过。

这验证的是**已录入标定参数和当前几何模型下的投影数学校核**。现场仍需用板面九点标定和堆高试块测量真实外参；标定残差可在“指引编排”页录入，超过预算时系统会提示重新标定。

## 已知边界

- DXF 导入是轻量实体解析器，覆盖常见 LINE/LWPOLYLINE/POLYLINE/CIRCLE/ARC，不解析块参照和样条曲线。
- 线束圆管使用低面数程序化网格；遮挡报告用胶囊近似，未做整束真实缠绕外形。
- 浏览器 WebGL2 最大投影仪数量在 shader 中设为 4，种子方案为 3。
- 首次进入指引页会同步/分片计算 200 步报告，低端设备可能需要数秒。
